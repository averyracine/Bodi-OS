# SEO content

Create content that ranks and converts. Prioritize search intent, message
match, and on-page SEO fundamentals. Where useful, ground keyword and
performance decisions in **real Google Search Console data** (via Supermetrics
or Windsor.ai) rather than guessing.

## Per-brand intent & topics

- **funsculpting.com** — local + informational intent for body contouring /
  aesthetics. Topics: "does [treatment] work", "[treatment] near me", cost,
  before/after expectations, recovery, comparisons. Include local SEO (city +
  service pages), clear consultation CTAs. Stay compliant — no guaranteed
  outcomes, cite reputable sources for claims.
- **inspiredsurgicalsupplies.com** — commercial + transactional intent. Topics:
  product/category pages, buying guides, spec comparisons, compliance/standards,
  bulk purchasing. Optimize product descriptions and category copy at scale.
- **inspiringphysicians.com** — informational + community intent for physicians.
  Topics: career, burnout, practice growth, CME, finance for doctors. Tone:
  credible peer-to-peer; lead-magnet CTAs (guides, webinars, newsletter).

## Workflow

1. **Target & intent** — identify the primary keyword + intent, and 3–8
   secondary/semantic terms. If GSC is connected, pull top queries/impressions
   for the site to find real opportunities (rising queries, page-2 keywords).
2. **Brief** (if planning) — deliver: URL slug, title tag (≤ 60 chars), meta
   description (≤ 155 chars), H1, H2/H3 outline, target keywords, word-count
   range, internal links, and the CTA.
3. **Draft** (if writing) — write the full piece to the brief: intent-matching
   intro, scannable H2/H3 structure, keyword used naturally (no stuffing),
   FAQs targeting related queries, and a clear CTA. Add schema suggestions
   (Article, FAQ, Product, LocalBusiness) where relevant.
4. **On-page SEO checklist** — title/meta, one H1, logical headings, keyword in
   first 100 words, internal + authoritative external links, image alt text,
   readable URL, FAQ/how-to schema.

## Output

- For briefs: a structured brief block ready to hand to a writer.
- For drafts: publish-ready Markdown with front-matter (title, meta description,
  slug, keywords) so it can drop into a CMS. Offer a matching hero image via
  `nano-banana`.

## Guidance

- Write for the searcher first, the crawler second.
- One primary keyword per page; don't cannibalize across pages.
- Match the funnel stage to CTA (informational → soft CTA; commercial → strong).
- Keep medical/professional claims accurate and, where needed, sourced.
